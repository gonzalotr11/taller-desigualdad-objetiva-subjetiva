# Mediciones de desigualdad objetiva y subjetiva

Materiales de apoyo del taller sobre convergencias, desajustes y configuraciones sociales en el estudio de la desigualdad.

## Contenidos

- Presentación general.
- Análisis de correspondencias múltiples.
- Clases latentes de inseguridad económica.
- Transiciones de endeudamiento.

## Datos

Los datos originales no se distribuyen en este repositorio.

Los documentos HTML se publican como materiales pedagógicos del taller.
